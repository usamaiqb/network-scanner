Network Scanner 是一款快速的 WiFi 与 IP 扫描工具，可以找出局域网内的每一台设备，并显示其 IP 地址、主机名、开放端口和设备类型。无广告、无追踪、无需 root。

查看谁在蹭你的 WiFi，发现陌生设备，找到打印机、摄像头或智能家居设备的 IP 地址，检查路由器和局域网中的开放端口。所有扫描均在手机本地离线完成，应用基于 GPL-3.0 协议完全开源。

<b>主要功能</b>

• 局域网扫描：Ping 扫描（支持 TCP 回退）、ARP、mDNS / Bonjour、SSDP / UPnP 与 NetBIOS 设备发现
• 端口扫描：扫描常用端口并识别服务与版本，或扫描全部 65,535 个端口
• 设备识别：主机名、厂商、型号、操作系统指纹与设备类型（手机、笔记本、电视、路由器、打印机、NAS）
• 在 Android 系统允许的范围内显示 MAC 地址，厂商信息使用应用内置的离线数据库查询
• 重命名设备并设置自定义图标
• 长按即可复制任意详情，点击 Web 端口即可在浏览器中打开
• 支持通过 WiFi、以太网或 VPN 扫描，端口可自定义

<b>权限说明</b>

• <b>附近的 WiFi 设备</b>：自 Android 16 起，访问局域网内的设备必须获得此权限
• <b>位置信息（可选）</b>：仅用于显示 WiFi 网络名称（SSID），绝不用于追踪
