Network Scanner 是一款快速的 WiFi 与 IP 扫描工具，可以列出局域网内的每一台设备，并显示其 IP 地址、主机名、开放端口和设备类型。无广告、无追踪、无需 root。

无论你是在排查网络故障、检查网络安全状况，还是只想知道有谁在连你的路由器，Network Scanner 都能完全离线完成扫描。所有扫描均在本机进行，应用基于 GPL-3.0 协议完全开源。

<b>主要功能：</b>

• 快速扫描 WiFi，发现局域网内的所有设备
• Ping 扫描并支持 TCP 回退，可发现屏蔽 ICMP 的设备
• 显示设备详情，包括 IP 地址、主机名与设备类型
• 端口扫描，识别开放端口与运行中的服务
• 支持全端口扫描（65,535 个端口），满足深度分析需求
• mDNS / Bonjour 服务发现，支持 AirPlay、Chromecast、打印机、SSH、SMB 等
• 操作系统指纹识别，可区分 Windows、Linux、macOS、路由器与打印机
• 在 Android 系统允许的范围内显示 MAC 地址及厂商信息。较新的 Android 版本出于隐私考虑限制了 MAC 地址的可见性，检测到随机（私有）MAC 地址时会予以标注
• 厂商信息查询使用应用内置的本地数据库，不会向任何远程服务器发送数据
• 简洁的 Material Design 3 界面
• 自定义设备：可重命名设备并设置专属图标
• 可选择网络接口（WiFi、以太网、VPN），扫描参数支持自定义

<b>谁在蹭我的 WiFi？</b>

• 查看连接到网络的每一台设备及其 IP 地址
• 发现陌生或未经授权的设备，识别蹭网行为
• 识别设备类型——手机、笔记本、电视、路由器、打印机、NAS 等
• 检查开放端口，找出网络中的安全隐患
• 排查网络连接故障
• 监控家庭或办公网络

<b>隐私优先：</b>

• 无广告、无追踪器、无数据分析
• 所有扫描均在本机完成
• 不上传任何内容，扫描结果绝不离开你的手机
• 仅申请必要权限
• 100% 开源（GPL-3.0），代码可供审计

<b>权限说明：</b>

Network Scanner 仅申请扫描所必需的权限：

• <b>网络访问</b>——用于与局域网内的设备通信。

• <b>WiFi 状态</b>——用于确认当前连接状态并识别待扫描的网络。

• <b>附近的 WiFi 设备</b>——发现局域网设备所必需。Android 正在逐步收紧对局域网的访问限制：自 Android 17 起，应用必须获得局域网权限才能访问局域网内的设备。缺少该权限将无法扫描。

• <b>位置信息（可选，绝不用于追踪）</b>——仅用于读取并显示 WiFi 网络名称（SSID）。不授予此权限也可正常扫描。
