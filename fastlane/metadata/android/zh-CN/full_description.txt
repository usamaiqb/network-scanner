Network Scanner 是一款快速、轻量且注重隐私的工具，用于发现和分析 WiFi 网络上的所有设备。无论您是网络管理员、技术爱好者，还是仅仅想知道谁连接了您的路由器，Network Scanner 都能让您即时掌握局域网（LAN）的设备情况——完全离线运行，无广告、无追踪、无数据收集。

<b>主要功能：</b>

• 快速 WiFi 网络扫描，发现局域网中的所有设备
• Ping 扫描并带有 TCP 回退，可检测屏蔽 ICMP 的设备
• 详细的设备信息，包括 IP 地址、MAC 地址和主机名
• MAC 厂商查询，并识别随机化（私有）MAC 地址
• 操作系统指纹识别，识别 Windows、Linux、macOS、路由器及打印机
• 端口扫描，识别开放端口和运行中的服务
• 全端口扫描（全部 65,535 个端口），用于高级网络分析
• mDNS / Bonjour 服务发现，支持 AirPlay、Chromecast、打印机、SSH、SMB 等
• 设备类型检测与分类
• Material Design 3 界面，现代直观的 UI
• 自定义设备：重命名设备并分配自定义图标
• 接口选择（Wi-Fi、以太网、VPN）与可自定义的扫描设置

<b>谁在连接我的 WiFi？</b>

• 查找连接到你 WiFi 网络的所有设备的 IP 地址
• 发现网络中的未知或未授权设备
• 识别设备类型——智能手机、笔记本电脑、电视、路由器、打印机、NAS 等
• 检查开放端口，提升网络安全性
• 排查网络连接问题
• 监控家庭或办公网络

<b>隐私优先：</b>

• 无广告或追踪
• 无分析或数据收集
• 无需外部互联网连接——所有流量均留在本地网络中
• 所有扫描均在设备本地完成
• 仅申请必要权限
• 100% 开源（GPL-3.0）

<b>权限说明：</b>

Network Scanner 仅申请网络扫描所必需的权限：
• 网络访问 - 与网络上的设备通信
• WiFi 状态 - 检查是否已连接到 WiFi
• 附近的 WiFi 设备 - 用于发现局域网中的设备。在 Android 16 及更高版本中，Android 要求此权限才能进行任何局域网通信，因此缺少该权限将无法扫描
• 位置（可选，绝不用于追踪）- 仅用于读取您的 WiFi 网络名称（SSID）。没有此权限也可以扫描

Network Scanner 完全无广告、无追踪器，并尊重您的隐私。所有代码均为开源且可审查。
